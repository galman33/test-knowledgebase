# מי1 / קויוטי (MI1/Coyote) - זאביק

## סקירה כללית
אפליקציית לימוד קריאה לילדים. האפליקציה מלמדת מילים דרך משחקים אינטראקטיביים, סיפורים וחוויות למידה מותאמות. המוצר העיקרי הוא "זאביק" - אפליקציה ללימוד קריאה לילדים בעברית.

## פרטים בסיסיים
- **סטטוס**: פעיל
- **תאריך התחלה**: 2023-03
- **אנשי קשר**: נועם, אור, ניב, אורן, יסכה, לילי
- **טכנולוגיות**: Unity, Mobile (iOS/Android), Web

## גרסאות עיקריות
- **V4**: הרחבת תכנים, 16-32 מילים, סיפורים אינטראקטיביים, Mad Libs
- **V5**: שיפורים נוספים
- **V6**: Session Generator, Endless mode, שיפורי UX

## יכולות עיקריות
- לימוד מילים (שמות עצם, תארים, פעלים)
- משחקים מגוונים עם סקינים שונים
- סיפורים אינטראקטיביים עם מדבקות
- Mad Libs - משחק מילים
- Progress tracking ואנליטיקות
- QA Tool לבדיקות

## תכונות נוספות
- Bubble Game
- Session Generator - יצירת סשנים אוטומטית
- Target Story - סיפור מטרה
- Narration controls
- ספר פיזי של זאביק (בתכנון)

- יולי 2023: דיון על V5
- יולי 2024: תכנון V6
