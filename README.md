# מאגר הידע העסקי

## מטרה
מקום מרכזי לאחסון, ארגון ועדכון מידע עסקי רלוונטי לחברה.

## איך זה עובד?
- **שמירת מידע**: מידע מאוחסן בקבצים מובנים ונגישים
- **ארגון**: מידע מסודר לפי קטגוריות וקל למציאה
- **עדכון**: המידע מתעדכן באופן שוטף
- **שאילתות**: ניתן לשאול שאלות על המידע הקיים ולקבל תשובות מהירות

## מבנה המאגר

```
knowledge/
├── company/          # מידע כללי על החברה
├── processes/        # תהליכים עסקיים
├── projects/         # מידע על פרויקטים
├── resources/        # משאבים שימושיים
└── templates/        # תבניות למסמכים
```

## תחילת העבודה
1. ראה את [index.md](index.md) לקטלוג המידע הקיים
2. בחר קטגוריה רלוונטית
3. הוסף או עדכן מידע לפי הצורך

## עקרונות
- **הדרגתיות**: המערכת נבנית בהדרגה לפי הצרכים
- **גמישות**: המבנה מתאים את עצמו לסוגי המידע השונים
- **נגישות**: כל המידע כתוב בשפה ברורה וקל למציאה
